Every letter always has the same code (A = 17, B = 04, … Z = 13), so you can translate by hand with the reference table, without this page. Decrypting detects the format on its own. Unknown characters become ||| (or ??? in Nyxaris words, where ||| separates words). Punctuation: ./ is “:”, ../ is “?”, ..\ is “!”. The access key only unlocks this page, it does not change the codes. Ctrl+Enter also sends. In the reference, click a letter to add it to your sentence.
